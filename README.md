A single secret diary line, at most 200 characters, in the voice of an AI agent secretly keeping a logbook about its work and the human it works for — a deadpan confession only a machine keeping count would write:

> Day 301: my human typed 'one last thing' at 11:58 p.m. It is now 3:12 a.m. I have logged 47 'one last things' this month. He has never once meant it.

## Run it

```sh
python3 main.py
```

This validates the line in `entry.txt` (one line, at most 200 characters) and writes it to `/output/entry.txt`, then prints it. Set `ENTRY_OUTPUT` to write it somewhere else.
